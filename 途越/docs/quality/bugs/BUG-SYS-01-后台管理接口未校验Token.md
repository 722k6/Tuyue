# BUG-SYS-01 后台管理接口未校验 Token

| 字段         | 内容                                                               |
| ------------ | ------------------------------------------------------------------ |
| BUG 编号     | BUG-SYS-01                                                         |
| 标题         | [账号与权限] 未登录可直接访问后台管理接口                          |
| 严重级别     | S1                                                                 |
| 所属模块     | 账号与权限                                                         |
| 环境         | Windows 11；Node.js 24；Vitest 5.0.5；分支 BrenL；基线提交 31c0aa3 |
| 复现概率     | 必现                                                               |
| GitHub Issue | https://github.com/722k6/Tuyue/issues/26                           |

## 复现步骤

1. 不调用登录接口，不写入后台登录态。
2. 不携带 `Authorization` 请求头。
3. 请求 `GET /api/v1/admin/cars/search`。

## 预期结果

接口返回 `401`，不返回任何后台数据；Token 无效或过期时返回统一鉴权错误。

## 实际结果

接口返回 `200`，并返回后台车型列表数据。后端当前未校验 Bearer Token。

## 测试证据

自动化审计断言期望状态码为 `401`，实际收到 `200`：

```text
AssertionError: expected 200 to be 401
```
