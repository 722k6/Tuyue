## 复现步骤

1. 启动 `pnpm dev`，浏览器打开 http://localhost:5174
2. 用 `admin / Admin@123` 登录后台
3. 进入「车型管理」，找到 `ty-suv-001`（途越远行）
4. 点击行内「参数」按钮打开参数抽屉
5. 观察抽屉顶部的分组区域

## 预期结果

1. 顶部显示动力 / 尺寸 / 安全 / 智能 / 其他 5 个可切换标签，标签带参数条数
2. 点击标签只显示当前分组下的参数
3. 「新增参数」按钮作用于当前分组

## 实际结果

没有标签栏，5 个分组共 11 条参数纵向堆叠在同一页，无法按分组切换查看与新增。

## 影响范围

参数保存、回显、重复代码校验均正常，缺陷只影响后台分组切换的展示交互；参数仍能通过堆叠列表逐个编辑。

## 修复建议

`apps/admin/src/main.ts` 手动注册 Element Plus 组件，注册列表中缺少 `ElTabs`、`ElTabPane`，`<el-tabs>` 被当作未知元素渲染，标签栏不生成、所有 `<el-tab-pane>` 同时展开。在 import 与注册数组两处补上这两个组件即可（全项目仅 `CarParametersDrawer.vue` 使用 tabs）。
